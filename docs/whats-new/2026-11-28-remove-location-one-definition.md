### Remove Location Info catches every place name
- An original copied with **Remove location info** is now refused when its only location is a country code, a place named in its IPTC (IIM) block, or an IPTC Extension Location Created or Shown. A video clip's original is refused too: export the clip in another format instead.
- Country codes and place names stored only in a photo's IPTC (IIM) block are now read on import.
