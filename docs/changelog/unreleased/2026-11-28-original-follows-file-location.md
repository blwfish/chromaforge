## Import, export and formats

- **Originals follow the file's location:** the private-location rule and the Original check decided from the library's GPS, while an Original copy carries the file's own. After the position was cleared (`gps_removed`) or moved out of a private location, the file's position went out. An Original is now refused when the file's own position is inside a private location, or when the library's was cleared and the file still holds one (GPS only: its place names stay unless Remove Location is on).
