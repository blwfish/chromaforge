## Import, export and formats

- **One definition of a location for Remove Location Info:** what counts as a location was written out three times (the rendered export, the Original's sidecar, the check before an original is copied) and the copies disagreed: the check missed a country code and the IPTC Extension's Location Created / Shown, never read IPTC-IIM place names, and copied a video clip with its QuickTime location. All three now use `lcc_meta::Metadata::has_location` / `clear_location` and `LOCATION_XMP_PROPERTIES`; IIM datasets 2:90, 2:92, 2:95, 2:100 and 2:101 are read; a video clip's original is refused under Remove Location (its container can't be fully checked).
- A country code stated only in XMP or IIM now reaches the metadata read from a file (it was dropped when merging the two).
